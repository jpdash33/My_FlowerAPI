# 🌸 Flower API

A simple Flower API built using **Python and Flask**.

The project allows users to search for a flower by name and view information such as its color, type, lifespan, uses, and location.

## ✨ Features

- 🔍 Search flowers by name
- 🌸 Display flower information
- 📚 100 flower records
- 🐍 Flower data stored in a Python dictionary
- ⚡ Flask API for handling requests
- 🎨 Simple responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## 🚀 How to Run

### 1. Install Flask

```bash
pip install flask
```

### 2. Run the application
```
python app.py
```
